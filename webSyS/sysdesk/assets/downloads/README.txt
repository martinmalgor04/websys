Colocá aquí el instalador con este nombre exacto:

  SysDesk.exe

Ruta en cPanel (FTP / Administrador de archivos):

  public_html/sysdesk/assets/downloads/SysDesk.exe

La descarga del sitio usa download.php en la raíz de sysdesk.
Subí también download.php si actualizás solo el .exe.

Nota: la carpeta sysdesk/ no se despliega con GitHub Actions;
subí el .exe y los PHP manualmente por FTP.
