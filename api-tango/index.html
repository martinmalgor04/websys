Cómo autenticarse

No hay login ni token de sesión: todas las llamadas llevan dos headers. La base es siempre https://connect.axoft.com/Api.

  1. Generá tu token de desarrollador en Tango web: menú de usuario → Desarrollador → Generar. Es un GUID que va en el header ApiAuthorization.
  2. Anotá el ID de empresa: es el número que sigue a company/ en la URL de tu Tango web. Va en el header Company.
  3. El token hereda los permisos y el perfil del usuario de Tango que lo generó. Si un proceso responde 401, casi siempre es un tema de permisos de ese usuario, no del token. 
# Ejemplo: listar clientes (proceso 2117)
curl -X POST \
  https://connect.axoft.com/Api/GetApiLiveFullOpenData?process=2117 \
  -H "ApiAuthorization: <TU_TOKEN>" \
  -H "Company: <ID_EMPRESA>" \
  -H "Content-Type: application/json" \
  -d '{"PageNumber": 1, "PageSize": 50}'
